# Problemas frecuentes con gift cards

| Situación | Qué hacer | Qué NO hacer |
|-----------|-----------|--------------|
| Código “inválido” | Verifica typos; busca código en Giftcards; confirma que esté aprobada | Crear segundo código sin anular el primero |
| Saldo insuficiente | Cobrar diferencia o usar otro código | Forzar monto mayor al saldo |
| Programada no llegó | Mira el pin **Envío** (filtro Envío fallido); lee el error; **Reenviar ahora** | Aprobar de nuevo duplicado |
| Email en spam | Pide revisar spam; reenvía manual | Asumir que falló el sistema sin revisar |
| Doble cargo / dos emails | Pausa; contacta **técnico** con códigos y horas | Enviar más códigos “de regalo” sin auditoría |
| Cliente perdió código | Busca en Giftcards por email comprador; reenvía | Inventar código nuevo sin registrar |
| Transferencia sin aprobar | Solicitud sigue pendiente hasta aprobar | Dar código antes de ver pago |

## Cuándo contactar al técnico

Duplicados de envío, saldos que no cuadran con movimientos, códigos que desaparecen del listado.
