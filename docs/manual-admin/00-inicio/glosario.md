# Glosario — palabras que usamos en el sistema

Definiciones en lenguaje sencillo. Si un término aparece en el manual, busca aquí primero.

| Término | Significado |
|---------|-------------|
| **Pre-reserva** | Reserva creada en la web **sin pago confirmado aún**. Tiene estado **Activa** y vence en **2 horas** si no se paga. |
| **Reserva confirmada** | Cliente pagó (total o parcial según reglas). Estado **Confirmada**. |
| **Reserva expirada** | Pasaron 2 horas sin pago (o se canceló). El cupo puede liberarse. |
| **Pendiente de verificación** | Cliente subió comprobante de transferencia; admin debe aprobar o rechazar. |
| **Código de reserva** | Identificador corto que ve el cliente (para comprobante o consultas). |
| **Comprobante** | Captura o PDF de transferencia bancaria que envía el cliente. |
| **Cupo / capacidad** | Plazas disponibles en un horario y técnica (torno, modelado, etc.). |
| **Override admin** | Forzar una acción aunque el sistema advierta conflicto (solo personal autorizado). |
| **Reagendar** | Mover la clase a otra fecha/hora. |
| **Política sin reembolso** | Si la clase es en **menos de 48 horas**, el cliente debe aceptar que no hay devolución al cambiar o cancelar. |
| **Paquete de clases** | Compra de varias clases con plazo desde la primera clase: 4 clases → 4 semanas; 8 → 2 meses; 12 → 3 meses. |
| **Clase suelta** | Una sola sesión, sin paquete. |
| **Open Studio / Estudio abierto** | Modalidad especial de producto; ver productos. |
| **Experiencia grupal** | Reserva para 2+ personas con reglas de técnicas mixtas. |
| **Experiencia de parejas** | Dos personas, un cupo de pareja. |
| **Upsell de pintura** | Cliente ya tiene pieza hecha y agenda solo sesión de pintura. |
| **Entrega** | Registro de piezas terminadas para retiro del cliente. |
| **Entrega atrasada (overdue)** | Fecha programada de entrega ya pasó y aún no está lista ni completada. |
| **Pintura (servicio)** | Flujo de cobro y agenda de pintura sobre una entrega. |
| **Gift card / tarjeta regalo** | Saldo prepagado con código para usar en reservas. |
| **Hold (retención)** | Bloqueo temporal del código gift card mientras alguien paga (evita doble uso). |
| **Envío programado** | Gift card que debe llegar en fecha/hora futura (hora Ecuador). |
| **Consulta grupal** | Formulario de interés; **no** crea reserva automática. |
| **Evento corporativo** | CRM para empresas; etapas desde contacto hasta cierre. |
| **Solicitud de factura** | Cliente pidió factura; finanzas la procesa fuera y marca en sistema. |
| **Sincronizar** | Refrescar datos del panel admin. |
| **Mis clases** | Portal donde el cliente ve sus reservas e inicia sesión con email. |
| **Marcación** | Registro entrada/salida de empleados. |
| **Cuadre / caja** | Cierre diario de movimientos de caja en `/cuadre`. |
