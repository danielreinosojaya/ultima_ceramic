# Paquetes y clases sueltas (cliente)

## Qué elige el cliente

| Opción | Descripción |
|--------|-------------|
| **Paquete** | Varias clases (4, 8, 12…) con ventana de tiempo para usarlas |
| **Clase suelta** | Una sola sesión |
| **Clase introductoria** | Primera experiencia promocional |

## Pasos en web

1. Tipo de experiencia → técnica (torno / modelado).
2. Elige fechas/horas disponibles (puede ser varios slots en paquete).
3. Datos personales y participantes.
4. Resumen y pago.
5. Confirmación o **pre-reserva 2 h** si paga después.

## Qué hacer admin después

| Resultado | Acción |
|-----------|--------|
| Pagó online | Aparece confirmada en calendario |
| Transferencia | Revisa [Pre-Reservas](../02-pre-reservas-y-pagos/panel-pre-reservas.md) |
| No completó pago | Expira en 2 h |

## Paquete: reglas extra

- Ventana de uso desde la **primera clase**:
  - **4 clases** → máximo **4 semanas**
  - **8 clases** → máximo **2 meses**
  - **12 clases** → máximo **3 meses**
- Reagendos limitados — ver [Políticas](../14-apendices/politicas-de-tiempo.md).
